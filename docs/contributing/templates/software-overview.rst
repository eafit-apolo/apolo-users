.. _minimap2:

Minimap2
========

Minimap2 aligns DNA and mRNA sequences against a reference genome. It is
used mainly to map long sequencing reads (PacBio, Oxford Nanopore).

- **Website:** `github.com/lh3/minimap2 <https://github.com/lh3/minimap2>`_
- **License:** MIT

*****
lefse
*****

LEfSe (Linear discriminant analysis Effect Size) [1]_ determines the features
(organisms, clades, operational taxonomic units, genes or functions) most
likely to explain differences between two or more biological conditions,
combining statistical significance testing with an estimate of effect size.

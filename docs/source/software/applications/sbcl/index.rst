****
SBCL
****

Description
-----------

SBCL (Steel Bank Common Lisp) is a high-performance Common Lisp compiler. It is an open source derivation of CMUCL, providing an interactive environment with a high-performance native compiler, debugger, and profiling support. SBCL is widely used as a robust platform for compiling and running symbolic computation systems such as Maxima.

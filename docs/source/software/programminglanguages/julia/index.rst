Julia
=====

Julia is a high-level, high-performance programming language for numerical
and scientific computing. It is compiled just in time, so simple scripts run
at speeds close to C or Fortran, and it has built-in support for threads,
distributed computing and GPUs.

- **Website:** `julialang.org <https://julialang.org>`_
- **License:** MIT
